# 桌面端设计变量（静器）

> 建立：2026-10-14（U1）· 依据：维护者 2026-10-14 选定的视觉方向「A 静器」，方向稿见 [CODEX_RUNTIME_PROMPTS.md](../CODEX_RUNTIME_PROMPTS.md)「界面参考」的 `design-refs/wevir-directions/`
> 代码：`apps/desktop/src/renderer/src/styles/`。界面改造分四步：U1 设计变量与字体（本文）→ U2 消息流折叠 → U3 libraries.dev 动效 → U4 首页与设置页。

## 1. 结构

三层，界面代码只碰最后一层：

| 层 | 文件 | 内容 |
|---|---|---|
| 原始色 | `palette.css` | 有名字的颜色：象牙（浅色中性色）、石墨（深色中性色）、金与铂金、四种状态色的 deep / pale 两档、七种头像色。手写，不随主题切换，每个都要被 `tokens.css` 用到 |
| 语义变量 | `tokens.css` | 全应用唯一的一套：背景、文字、边框、主按钮、品牌、状态、代码、头像、遮罩、阴影、圆角、字体。浅色在 `:root`，深色只认 `<html data-theme="dark">`，两块定义同一组变量 |
| Tailwind 主题 | `theme.css` | `@theme inline` 把语义变量映射成工具类（`bg-background`、`text-muted-foreground`、`rounded-xl`…）。Tailwind 自带的调色板与阴影用 `initial` 清空，`bg-red-500`、`text-white`、`shadow-xl` 不生成 CSS |

另有 `fonts.css`（随应用打包的字体，§4）、`markdown.css`（助手消息的排版，只用语义变量）。

暗色只认 `data-theme`：不认 `.dark` 类，也不直接跟 `prefers-color-scheme`。外观设置的“跟随系统”由 `theme/theme.ts` 解析后写进 `data-theme`。

浅色的中性色 U17.1 起换成乳白（§22），深色不变。静器没有彩色的强调色：主按钮、选中项、链接都是墨色，彩色只表示状态。状态色每种只有一档，文字、图标、圆点、描边与 `bg-warning/10` 这类淡底都用它（T5.2 的 `*-solid` 实色档已去掉）。

U3 起子会话头像是 bot-avatars 的小机器人（canvas 绘制），颜色要字面值，浅色、深色各六种写在 `session/avatar.ts`（方向稿 A 的头像配色）；thinking orb 的墨色（浅色 `#2b2a26`、深色 `#e9e8e2`）写在 `fx/orb.tsx`，金属与光束的颜色是库的 gold、mono 预设。原来的 `--avatar-1` … `--avatar-7` 与它们的原始色已删掉。

T5.2 的 `--faint-foreground`（比说明文字更淡一级的提示色）已去掉，原来用它的地方改用说明文字：方向稿里时间、提示这类文字也是说明文字色，而且它对背景不到 4.5:1。

## 3. 圆角、阴影、字号

- **圆角**：`--radius-card`（12px）与 `--radius-control`（8px）。Tailwind 的阶梯由它们推导：`rounded-xs` 2、`sm` 4、`md` 6、`lg` 8、`xl` 12、`2xl` 16、`3xl` 20。消息输入框用 `rounded-3xl`（U12，照 Codex，§16）；卡片（审批卡片、设置里的列表卡片、窗格、对话框、浮层与菜单）用 `rounded-xl`，按钮、输入控件与列表项（左栏的行、菜单项、窗格标签）用 `rounded-lg`；嵌在卡片里的代码块、徽标用 `md` / `sm`。外层比内层大一阶。消息流里的执行过程不用卡片（U2：工作组与回合都是一行文字），子智能体标记与“N 个文件已更改”是 `rounded-full` 的小标签。
- **阴影**：只有一档 `--elevation`，Tailwind 的 `shadow-xs` … `shadow-lg` 都是它。卡片默认不带阴影，浮起的东西（消息输入框、浮层、菜单、审批卡片）才带。浅色 `0 1px 2px rgba(26,26,23,.05), 0 10px 30px -16px rgba(26,26,23,.18)`，深色 `0 1px 2px rgba(0,0,0,.4), 0 12px 32px -16px rgba(0,0,0,.6)`。
- **字号**：正文 `text-base` 14px / 行高 1.55；代码与控件 `text-sm` 13px；`text-xs` 12px。根字号仍是 16px，间距的 4px 网格不变。

## 4. 字体

全部随应用打包，不从网络加载（国内访问不了 Google Fonts；渲染进程的 CSP 只放行 `font-src 'self'`）。

| 变量 | 用途 | 字体 | 文件（`assets/fonts/`） |
|---|---|---|---|
| `--font-ui`（`font-sans`） | 界面与正文 | 拉丁字母 Mona Sans 2.0.27（可变字体，字重 200–900，带光学尺寸轴），中文用系统字体：PingFang SC / Hiragino Sans GB / Microsoft YaHei UI / Noto Sans CJK SC | `mona-sans.woff2` 134 KiB、`mona-sans-italic.woff2` 123 KiB |
| `--font-code`（`font-mono`） | 代码、路径、命令 | JetBrains Mono 2.304（可变字体，100–800），中文回落到系统字体 | `jetbrains-mono.woff2` 111 KiB、`jetbrains-mono-italic.woff2` 120 KiB |
| `--font-display`（`font-display`） | 标题宋体，只用在固定文案上（U4 的首页标题） | Noto Serif SC 2.003 Medium，按文案做的子集，CSS 里叫 `"Wevir Display"`；子集里没有的字回落到系统宋体 | `noto-serif-sc-display.woff2` 10.6 KiB |

- **中文正文不打包**：用系统字体（维护者 2026-10-14 定）。
- **Mona Sans 不负责中文语境的标点**：`fonts.css` 的 `unicode-range` 把“”‘’——…（U+201C/D、U+2018/9、U+2014、U+2026）排除在外，交给中文字体，免得中文句子里出现窄的西文引号与破折号。
- **标题宋体的子集**：文字在 `apps/desktop/scripts/build-fonts.py` 的 `DISPLAY_TEXT`，是首页标题各句式的固定部分（`zh-CN.ts` 的 `home.title.N.before` / `.after`，方向稿 A 原本只有“今天在 … 里做什么？”；工作区名用界面字体）。改这些文案要同时改 `DISPLAY_TEXT` 并重新生成，`i18n.test.ts` 会查出子集外的字；文案里出现子集外的字会回落到系统宋体，样子不一致。首次使用的引导标题“开始使用 Wevir”不在子集里，用界面字体。
- **重新生成**：`build-fonts.py` 从固定版本的来源（发布包或固定提交，按 sha256 校验）生成全部 woff2 与 `apps/desktop/licenses/fonts/*/OFL.txt`，输出可复现；用法写在脚本开头（可选工具 `fonttools==4.60.1`、`brotli==1.1.0`，与图标的 `outline-wordmark.py` 同一套）。Mona Sans 与 JetBrains Mono 只把 TTF 转成 WOFF2，不做别的改动：Mona Sans 的版权行保留了字体名 “Mona”，按 OFL 第 3 条，改动过的版本不能再叫这个名字，所以不能子集化。Noto Serif SC 的版权行没有保留字体名，可以子集化。
- **构建**：Vite 默认把小于 4 KiB 的资源内联成 `data:` URI，宋体子集会被 CSP 拦下；`electron.vite.config.ts` 让 `.woff2` 总是单独成文件。
- 来源、版本与许可证见 `assets/fonts/SOURCE.md` 与仓库根目录的 [`NOTICE`](../../NOTICE)。

## 5. 品牌

- `--brand`：浅色金、深色铂金，只用于品牌主标与品牌时刻（`assets/icons/README.md`）。界面里的主标组件是 `components/brand-mark.tsx`（几何取自 `assets/icons/source/mark.svg`，`text-brand`）；左栏不放主标与产品名，界面上只有首页品牌行（U4）用它。
- 字标与线性功能图标（lucide）用文字色，不用品牌色；首页品牌行的字标例外：是金属字（`fx/metal.tsx` 的 `MetalWordmark`，金属预设 gold，字色浅色金棕、深色铂金），算品牌时刻（U4）。
- 主标在浅色画布上约 3.4:1，够图形的 3:1，不能当文字色用。

## 6. 窗口与首帧的底色

`src/shared/theme.ts` 的 `THEME_BACKGROUND` 是两种主题的 `--background`。主进程的窗口底色用它（窗口缩放时露出的未绘制区域）；首帧前脚本 `public/theme-init.js` 在样式表生效之前按存储的主题给 `<html>` 涂上同样的底色，`theme.ts` 启动时去掉。

## 7. 校验

`styles/tokens.test.ts`（desktop 的 Vitest project）从 `palette.css` 与 `tokens.css` 读出浅色、深色两套变量：

- 正文、次正文、说明文字对所有底色（画布、侧栏、表面、次表面、代码底等）至少 4.5:1；主按钮的字、状态色（也用作文字）、语法高亮色对各自的背景至少 4.5:1；品牌色对画布、侧栏、表面至少 3:1。
- `--background` 等于 `THEME_BACKGROUND`；`shared/theme.test.ts` 核对首帧前脚本写的底色。
- `palette.css` 不随主题切换、每个原始色都被用到；`tokens.css` 的浅色块与深色块定义同一组变量；`fonts.css` 引用的字体文件都在，`assets/fonts/` 里没有多余的。

改色以后跑 `pnpm vitest run --project desktop`。淡底上的状态文字（如 `bg-warning/10` 上的 `text-warning`）没有算进去：混色要按 oklab 算，测试没有实现。

## 8. 改动的做法

- 改色：只改 `palette.css` 的原始色或 `tokens.css` 的引用，跑测试。
- 加语义变量：浅色、深色两块都写，需要工具类时在 `theme.css` 的 `@theme inline` 里加 `--color-<名字>`，在 §2 的表里登记。
- 组件里不写 `#…`、`rgb()`、写死的字体与圆角（`rounded-[4px]` 这类）；shadcn 新生成的原语若带这些，换成阶梯里的类名并在文件头写明改动。

## 9. 与方向稿的对应

方向稿 `src/styles.css` 的 `.app`（A 的浅色）与 `.app[data-dir='a'][data-mode='dark']` 里的变量与这里的对应：`--bg` → `--background`、`--side` → `--sidebar`、`--surface` → `--card` / `--popover`、`--surface-2` → `--muted` / `--accent` / `--secondary`、`--line` → `--border`、`--line-2` → `--border-strong`、`--ink` → `--foreground`、`--ink-2` → `--soft-foreground`、`--muted` → `--muted-foreground`、`--accent` / `--accent-ink` → `--primary` / `--primary-foreground`、`--brand` → `--brand`、`--run` / `--await` / `--ok` / `--bad` → `--running` / `--warning` / `--success` / `--destructive`、`--code-bg` → `--code-background`、`--shadow` → `--elevation`、`--radius` / `--radius-sm` → `--radius-card` / `--radius-control`、`--font-ui` / `--font-display` / `--font-mono` → `--font-ui` / `--font-display` / `--font-code`。方向稿里只有 B、C 用到的变量（`--glass`、`--grid`、`--f1`…）与加号按钮的专用色没有搬过来，U4 用到时再加；开关的 `--switch-thumb` U3 搬了（A 的浅色 `#ffffff`、深色 `#3a3c43`，取了最接近的原始色），`--switch-track` 用 `--muted`。

## 10. 首页与设置页（U4，设置页 U7 改）

- **首页**（`routes/home-route.tsx`，版式在 `session/new-session.tsx`；U14 起照 Codex 桌面端，新会话草稿页同一个版式）：品牌行（`BrandMark` 用 `text-brand`，加 `fx/metal.tsx` 的 `MetalWordmark`）与标题在内容区里输入框以上的部分上下左右居中、文字居中，块之间 20 px；标题有 8 种句式（“今天在 [项目] 里做什么？”“你想让我们在 [项目] 中构建什么？”等，`home.title.N.*`），首页挂载时随机取一种，换项目不变；`font-display`、500、`clamp(1.625rem, 3.4vw, 2.5rem)`，项目名是界面字体 600、0.86em、强分隔线色的虚线下划线，点开的项目菜单居中对齐。输入框（`Composer variant="home"`，焦点只用 border-beam 的 focus 预设表示，不换边框色；上面是环境栏，§16）贴底，宽度与位置同会话页（`max-w-content`、左右 24 px、下 20 px），发出第一条消息跳到会话页时不挪地方；窗口矮到放不下时上面那块滚动，输入框不动。U4 的“接着做”已去掉（维护者 2026-10-15 定）。顶栏在首页不画分隔线。
- **设置页**（`routes/settings-route.tsx`、`settings/settings-ui.tsx`；U7 起照 Codex 桌面端）：设置自己的侧栏 240 px、侧栏色，顶上是窗口按钮，下面 20 px 半粗的“设置”、胶囊形的搜索框（`bg-sidebar-accent/70`，聚焦时实色加焦点环），再下面是带 12 px 组名的页面列表，行的悬停与当前项同 §11 的左栏。内容一列最宽 720 px（`max-w-180`），页面标题 20 px 半粗，换页时淡入上移；下面是一组组卡片（`SettingsSection`：13 px 半粗的组名、可选的一行说明与右侧操作，组间 36 px）；卡片是 `LIST_CARD`，行（`SettingsRow`）至少 56 px 高，左边 13 px 中粗的名称与 12 px 说明文字色的说明，右边是控件。分段切换（`Segmented`）的轨道是次表面色，选中段是 `bg-switch-thumb` 加一圈分隔线，滑块在段间滑动 200 ms。模型服务与项目的列表行左边是 36 px 的图标框（画布底色、分隔线描边），服务用各自的标志（§12）。空列表是强分隔线色的虚线框。

## 11. 窗口框架与侧栏（U5）

- 侧栏的行（`layout/sidebar.tsx`）：悬停 `bg-sidebar-accent/70`，当前项 `bg-sidebar-accent`（表面色），颜色过渡 150 ms，不加描边（照 Codex 桌面端）。项目名用正文色，会话标题用次正文色，当前会话与未读的用正文色。
- 窗口按钮（后退、前进、侧栏开关）是 `icon-sm` 的 ghost 按钮，图标用说明文字色；`--window-controls-width` = 88 px。
- 布局过渡：侧栏、窗格区的开合与它们的浮层都是 260 ms、`cubic-bezier(0.32, 0.72, 0, 1)`（`index.css` 的 `.layout-transition`，[desktop-layout.md](../architecture/desktop-layout.md) §11）。减弱动效时照全局规则缩成瞬时。
- “创建项目”对话框：卡片圆角、内边距 20 px；名称框 40 px 高、左边是文件夹图标；没选文件夹时是虚线框加一个胶囊形的“添加”按钮，选了之后是一行路径（等宽、截掉开头）与“更换”、移除。

## 12. 首次引导（U6）

## 14. 动效（U10）

- **曲线**（`styles/theme.css`）：`ease-smooth` = `cubic-bezier(0.22, 1, 0.36, 1)`，用于弹层、展开收起与元素出现（先快后慢、不回弹）；`ease-emphasized` = `cubic-bezier(0.32, 0.72, 0, 1)`，用于侧栏与窗格区开合与整幅滑入（§11）。颜色过渡仍是默认的 150 ms。
- **按钮**（`components/ui/button.tsx`）：颜色、边框、阴影与变换一起过渡 150 ms，按下缩到 97%（带下拉的按钮不缩）；输入框的发送键按下缩到 95%。
- **弹层**：菜单、浮层、提示出现与消失 150 ms；对话框出现 200 ms（放大加上移 8 px），关闭 150 ms，遮罩 200 ms。
- **展开收起**（`components/collapse.tsx`）：行高在 0fr 与 1fr 之间过渡 200 ms 并淡入淡出，内容从上方 4 px 落下（U24），收起结束后卸载内容；用在工作组与其中的详情、折叠块（`session/disclosure.tsx`）与左栏：整节“会话 / 项目”的收起、每个项目的会话列表，以及“显示更多 / 收起”多出来的那几行（U24，`layout/sidebar.tsx` 的 `MoreList`；当前会话排在后面时全部列出、不显示按钮）。
- **出现**：换会话时整页淡入 200 ms；贴底时消息流末尾新到的块淡入上移 300 ms（首次渲染与向前展开的旧消息不动）；审批卡片、待发区及其中的消息、设置页的提示淡入上移；首页的品牌行、标题、输入框、最近会话依次淡入上移，每块 500 ms、相隔 60 ms。
- **减弱动效**：全局规则把动画与过渡缩成瞬时（`index.css`），以上都遵守。

- 等用户处理时（等待审批、等待回答），消息流里当前动作那一行是警示色 10% 底、警示色字的小标签（`live-indicator.tsx` 的 `AWAITING_PILL`，照 Claude Code 的“Needs your input”），thinking orb 停住。

## 20. 执行过程（U16）

在 U2 的折叠（工作组一行摘要、回合收进“已处理 …”）上，照 Claude Code 与 Codex 桌面端各取一处（`session/work-group.tsx`、`session/tool-model.ts`）：

- **摘要（Claude Code）**：读取、修改、新建只涉及一个文件时写出文件名（不含目录，正文色），例如“创建了 index.test.ts，运行了 1 条命令 +5 −0 ›”；其余仍是计数。Codex 补丁里新建的文件（`changes[].kind` 是 `add`）从“修改了”分出来算“创建了”，先建后改的只算新建。有工具调用时不到 1 秒的思考不写进摘要；只有思考的组照写，不到 50 ms（显示不出时长）写“思考过”，展开后的思考行同理。
- **进行中（Codex）**：进行中的那一组默认展开，组头是当前动作（thinking orb、闪光文字、已用时间、向下的箭头），下面逐条列出这一组已经做完的步骤；正在运行、等审批的工具与还在流出的思考由组头代表，结束后才列进来。这一组做完（后面有了正文、或回合结束）就按 U10 的展开收起过渡收回成摘要；用户在进行中点过的照用户的。回合结束后整段仍收进“已处理 …”。

## 21. 窗格区与消息流一体（U17）

- **底色**：窗格区（停靠、最大化、窄窗口的右侧浮层）与主窗格同是画布色 `--background`，不再用侧栏色。窗格（`layout/pane.tsx`）仍是画布底、分隔线描边、`rounded-xl` 的卡片，不带阴影，和消息流只靠这圈细边框与圆角分开；窗格之间、窗格与主窗格之间 8 px 的间距里露出的也是画布色，分隔条平时看不见，悬停、聚焦、拖动时才出现 1 px 的运行色线。
- **为什么**：原来窗格区外层是侧栏色、窗格是画布色，卡片四周露出一圈侧栏色，主窗格和窗格区之间像隔着一条色带（浅色偏灰、深色偏黑），不像一个整体。Claude Code 桌面端的会话侧栏与后台任务窗格（`design-refs/claude-code-parallel-sessions/` 08–12）也是和消息流同一个底色，卡片只用细边框。侧栏色只留给左栏（它是导航，不是内容），设置页的导航同理。
- **浮层**：窄窗口里窗格区盖在主窗格上时同样是画布色，和下面的消息流靠左边的分隔线与浮层阴影分开（`components/ui/sheet.tsx`）。
- 顶栏的下边线横跨主窗格与窗格区，两边是同一条线、同一个底色。

## 22. 浅色换成乳白（U17.1）

- 维护者 2026-10-15 要浅色整体像 Codex 与 Claude Code 桌面端那样是乳白色。量了 `design-refs/` 里的截图：Claude Code 的画布是 `#fcfbfa`（会话侧栏、消息流、清单），卡片与窗格是纯白 `#ffffff`、边框约 `#e4e3e2`；Codex 是纯白 `#ffffff`、面板 `#f2f3f3`。取 Claude Code 的乳白（比 Codex 的纯白暖一点，和静器的墨色、金色主标相配）。
- 象牙色阶（`palette.css`）整体提亮、去掉偏黄：表面 `#ffffff`、画布 `#fcfbfa`、侧栏 `#f7f6f3`、次表面（悬停、弱填充、代码底）`#f2f1ee`、分隔线 `#e6e4e0`、强分隔线 `#d3d1cc`；文字三档（`#1a1a17`、`#45433d`、`#67635a`）、状态色、金色主标不变。原来侧栏比次表面深（`#ecebe4` 对 `#efede6`），现在侧栏只比画布深一点、比次表面浅，所以色阶 3、4 对调：3 是侧栏、4 是次表面，`tokens.css` 跟着改引用。
- 层级没变：侧栏 → 画布 → 次表面 → 表面。左栏仍比画布深一档（照 Claude Code，左栏与内容区之间靠这一点色差和一条分隔线），输入框、菜单、卡片是白底加分隔线与阴影浮在乳白上。
- 品牌图标（`assets/icons/`）的底色仍是品牌的象牙 `#f4f3ed`，与应用的浅色画布不再相同；`THEME_BACKGROUND` 与首帧前脚本改成 `#fcfbfa`（§6）。
- 对比度（§7 的测试）：底色都变亮了，文字对比度只升不降；金色主标对画布约 3.9:1、对表面约 4.1:1，仍够 3:1。

## 33. “变更”窗格（0.20.0）

照 T3 Code 的 diff 右栏，布局与行为见 [desktop-layout.md](../architecture/desktop-layout.md) §18。diff 由 @pierre/diffs 的虚拟化 CodeView 画在它自己的 shadow root 里，样式经 `unsafeCSS` 注入（`changes/styled-code-view.tsx`、`changes/diff-rendering.ts`），颜色全部取 Wevir 的语义变量，暗色跟着 `<html data-theme>` 走（Pierre 的主题 `pierre-light` / `pierre-dark` 只管语法高亮的颜色）。

- **表面**：代码底是画布色（`--code-background` 在窗格里设成 `--background`），字是正文色；上下文行同底，悬停行与分隔条比底色深一点（底色混 4–6% 正文色）。增删的行底是代码底混 12% 的成功色 / 失败色，行号格混 20%，改动的字再深一档（30%）；左边的增删竖条用成功色 / 失败色。静器没有彩色强调色，彩色只表示增删。
- **字**：代码 12 px、行高 20 px 的等宽字（`--font-code`）；文件头、分隔条与工具栏是界面字体。
- **工具栏**：40 px 高、下边一道分隔线，左边 `sm` 的幽灵按钮写范围与 ⌄，右边等宽的 +N −M（成功色、失败色）与一排 `icon-sm` 图标按钮（刷新、全部展开 / 收起、统一、并排、自动换行），中间一道 16 px 高的分隔线；按下的切换是 `accent` 底。提示写在按钮的提示里，不另起一行。刷新时图标转动（减弱动效时不转）。
- **文件头**：32 px（与虚拟列表的 `diffHeaderHeight` 一致）、画布底、下沿 1 px 分隔线（内阴影，不占高度），吸顶。左边 14 px 的折叠箭头（展开时转 90°，200 ms `ease-smooth`），12 px 中粗的文件名，说明文字色的目录与“· 新增 / 已删除 / 重命名”，右边等宽的 +a −r。悬停是次表面色 60% 的底；焦点环画在里面。
- **分隔条**：24 px（与 `hunkSeparatorHeight` 一致）、12 px 说明文字色的“N 行未修改”，左边一格是展开按钮；悬停时字变正文色、底再深一点。
- **不加提示行**：大 diff 折叠与部分文件没给 diff 时工具栏下面不写说明。没给 diff 的文件列在最后，一行 24 px：等宽的路径（截掉开头）、说明文字色的原因、+a −r。
- **动效**：展开一个文件时正文淡入 200 ms（虚拟列表管几何，高度不过渡）；减弱动效时都不动（全局规则，shadow root 里另写了 `prefers-reduced-motion`）。

## 34. 界面语言（2026-10-15）

- **语言**：自动检测（默认）、English、简体中文、繁體中文、Français、Deutsch、Italiano、Español、日本語、한국어、Русский（维护者 2026-10-15 定，暂只支持这些）。自动检测按系统的首选语言列表取第一种支持的，中文按书写系统分简繁（`zh-Hant`、台湾、香港、澳门为繁体），都不支持时用英语。
- **设置 → 常规 → 语言**（`settings/language-picker.tsx`，照 Codex）：右侧 32 px 高的描边按钮写当前选择与 ⌄；点开是 256 px 宽的浮层，顶上是搜索（放大镜、无边框的输入，回车选第一项），下面“自动检测”在最前，各语言用自己的文字写名字，右边 12 px 说明文字色是它在当前界面语言里的叫法（与自称相同时不写），选中的一项中粗、右边打勾。搜索认自称、当前语言里的叫法与语言代码。
- **换语言**：选择存在本机；换成另一种语言时重新加载窗口（首帧前的主题脚本让重新加载不闪白），不做运行中的热切换。
- **字体**（`tokens.css` 末尾，按 `<html lang>`）：繁体用 PingFang TC / Microsoft JhengHei，日文用 Hiragino Sans / Yu Gothic，韩文用 Apple SD Gothic Neo / Malgun Gothic，免得汉字落到简体字形；标题宋体只有简体中文用 "Wevir Display" 子集，繁体、日文、韩文用各自的系统明朝 / 明體体，西文与俄文用系统衬线体（ui-serif / New York / Georgia）。拉丁字母一律 Mona Sans。
- **文案长度**：德语、俄语、法语通常比中文长一倍以上；按钮、芯片与菜单项按最长的语言检查是否截断，必要时只截断不换行（`truncate`）。
