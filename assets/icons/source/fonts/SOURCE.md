# Mona Sans Bold

- 仓库：https://github.com/github/mona-sans
- 来源路径：`fonts/static/ttf/MonaSans-Bold.ttf` 与 `OFL.txt`
- 固定提交：`4bc6ba8b354c36b4fb66d32cd67b4c1f2beb0a06`
- 许可证：SIL Open Font License 1.1，全文见 [OFL.txt](OFL.txt)。
- 使用：`scripts/icons/outline-wordmark.py` 提取 Wevir 字标的轮廓，结果在 `source/wordmark-paths.json`；没有修改或重命名字体。
- 所有由该字体生成的字标、组合标识 SVG 带相同的来源注释。主标与功能图标不是字体字形。
- 社交横幅的定位文案与域名也使用该字体，转曲数据为 `source/social-copy-paths.json`，由 `scripts/icons/outline-social.py` 生成；SVG 字体来源注释与字标相同。
