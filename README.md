# Wevir

Wevir 是面向中国大陆用户的**本地优先、开源、多模型、可跨设备接续的 Agent 工作台**，覆盖代码开发、文件、资料与办公任务。它以 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）为 Agent 执行内核，自己拥有 Local Agent Host、版本化的会话协议和桌面 / 命令行客户端。项目目前处于骨架阶段。
